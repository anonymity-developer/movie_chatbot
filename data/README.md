# Movie data

`movies.json` contains 964 TMDB-based movie records. `movielab_wiki/wikipedia/` contains 3,725 Korean Wikipedia article snapshots associated with those movies. Movie records link to TMDB pages, and document records link to their Wikipedia pages.

Movie metadata is subject to TMDB's terms. Wikipedia text is licensed CC BY-SA 4.0. Review the applicable attribution and reuse terms before distributing derived datasets.
