# 제출 전 셀프 체크리스트

| 확인 항목 | 상태 |
|---|---|
| Agent 요청 분석, Tool 선택·실행, 시간 판단, 재계획 및 상한 | 데모 API 테스트 및 전체 실행 로그 |
| 후속 조건 변경, 개별 상세 실패에도 계속 실행, 인사 시 Tool 없음 | 자동 테스트 |
| 단계·Tool·재계획 이벤트, 세션 분리, 로그 조회·삭제, 로거 실패 격리 | 자동 테스트 |
| 계획 중복 저장 안내, 수정·삭제, 세션 분리 | 자동 테스트 |
| 실연동 API 키 미설정 및 잘못된 Tool 입력 | 자동 테스트 |
| 브라우저 재계획, 계획 저장·수정·삭제, 로컬 캘린더 등록, 로그 상세, FastAPI 문서 | 헤드리스 Chrome. `planner-demo.png`, `api-docs.png` |
| F3020 이상 판정 세 유형, 판정 불가, 정상 시 진단 호출 없음, 진단 실패 보존 | 자동 테스트 |
| F3021 계획 외 호출이 재계획을 유발, 사용자 고정 인자 보호, Worker LLM 구성 비교 | 자동 테스트 및 `worker-comparison.json` |
| F3022 문서 링크와 색인 없음 | 자동 테스트 |
| F3023 중복 등록 방지, 일정 충돌 반영, Google 요청 형식 | 로컬 및 모의 연동 자동 테스트 |
| GMS 임베딩과 Chroma 실검색 | `text-embedding-3-small` 1,536차원 반환. 한 작품으로 만든 별도 색인에서 근거 문서 5건 확인 |
| OpenStreetMap 실제 영화관 조회 | 강남역 실연동에서 Nominatim으로 이름·주소·지도 링크가 있는 영화관 3곳 확인(474ms). 다른 지역의 Overpass 실조회는 미확인 |
| GMS 플래너·KOBIS 실호출 | 강사 공지의 GMS Claude 경로를 사용한 강남역 실연동에서 영화 5편, 주변 영화관 3곳, 실행 로그 저장을 확인 |
| 실제 Google Calendar 조회·등록 | OAuth 연결 전. SQLite와 모의 Google 요청 형식은 검증 |
| 강사 배포용 공식 셀프 체크리스트 | 파일 미제공. 현재 문서는 명세의 자체 점검표 |
| 과제 Git 업로드 및 MM 제출 알림 | 실제 과제 경로와 제출 확인 필요 |

대표 실행은 `execution-logs.json`에 요청, 기대 상태, 실제 응답, 실행 시간, 단계와 Tool 결과를 담는다. `first_pass`, `replan_match`, `replan_limit`, `detail_failure`, `no_tool`은 합성 데이터를 사용한 별도 브라우저 세션 실행이다.
