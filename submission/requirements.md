# agenttrip 요구사항 정의서

## 도메인과 대상

특정 지역에서 주어진 시간 안에 볼 만한 영화를 고르고 관람 계획을 관리한다. 입력은 관람일, 시작 가능 시각, 종료 마감 시각, 지역이다. 저장 대상은 영화 제목, 관람일, 시작·종료 시각, 생성 시각이다.

| 대표 요청 | 외부 정보가 필요한 이유 |
|---|---|
| 내일 15:00 이후 강남에서 19:00 전에 끝나는 영화 | 후보의 러닝타임과 강남의 영화관 위치가 필요하다. |
| 내일 15:00 이후 강남에서 16:40 전에 끝나는 영화 | 일별 순위에서 나온 영화가 너무 길면 다른 집계의 후보를 보충해야 한다. |
| 내일 15:30 이후 강남에서 16:40 전에 끝나는 영화 | 이용 가능 시간이 짧아 모든 후보를 제외할 수 있다. 제외 사유와 재계획 종료를 설명해야 한다. |

## 요구사항 추적

| ID | 구현 및 확인 기준 |
|---|---|
| F3001 | 외부 Tool 카탈로그 및 입력·출력 스키마, 성공·실패 응답 |
| F3002 | 일별 후보의 ID·제목과 조회일 공개, 주간 후보 보충 |
| F3003 | 후보 ID로 러닝타임·등급·장르 조회, 누락 시 제외 |
| F3004 | 다른 공급자에서 영화관 이름·주소·장소 링크 조회 |
| F3005 | 날짜·희망 시각·지역·마감 추출, 누락 시 재질문 |
| F3006 | 분석 결과를 바탕으로 유효한 Tool 순서 선택, 인사는 호출 생략 |
| F3007 | 후보 ID를 상세 Tool에 전달하고 개별 실패 후 계속 진행 |
| F3008 | 러닝타임과 입장 여유를 합산하여 최종 시작 가능 시각 계산 |
| F3009 | 주간·이전 일별 후보로 최대 3회 재계획, 이미 판단한 ID 제외 |
| F3010 | 브라우저별 관람 조건을 저장하고 지정한 조건만 갱신 |
| F3011 | 후보·시간 기준·주변 영화관·집계 근거·제외 사유 표시 |
| F3012 | 단계, 모델의 판단 근거, Tool 요청·응답·소요 시간을 이벤트로 발행 |
| F3013 | 분리한 구독자가 브라우저 세션·실행 ID별 이벤트 저장 |
| F3014 | 사용자의 실행 로그 목록·상세·삭제 |
| F3015 | 관람 계획 생성·조회, 시간 중복 결과 안내 |

| F3017 | FastAPI 대화·계획·로그 API와 OpenAPI |
| F3018 | HTML·CSS·JS 대화 화면 및 계획 관리 |
| F3019 | 대기, Tool 오류, 키 누락, 단계·재계획 보기 |
| NF3001~NF3002 | 로컬 환경변수, 마스킹된 이벤트, 화면에 정제된 오류 코드·문구 |
| NF3003~NF3004 | 개별 오류 계속 처리, 치명적 인증·한도 오류 종료, 재계획 최대 3회 |
| NF3005 | 대표 요청의 소요 시간 기록, 실제 공급자 응답을 포함한 시간은 별도 확인 |
| NF3006 | 화면·API·Agent·Tool·이벤트·저장소 분리 |
| NF3007 | 공식 출처·쿼터 확인 경로는 Tool 정의서 참조 |

심화 항목은 필수 제출 검증 후 시간 여유가 있을 때 진행한다. 기존 Movie Lab의 영화별 검색과 질문은 별도 기능으로 제공한다.

## 기획 검증 상태

KOBIS 일별·주간 순위 및 상세와 카카오 로컬 조회의 입력·출력 계약은 공식 문서와 대조했다. 키 없는 환경에서 데모와 입력 오류를 검증했다. GMS·KOBIS·카카오 키를 사용한 실호출은 미검증이다. 박스오피스와 영화관 위치로 상영 일정을 확인할 수 없어서, 방문 가능 시간의 계산과 실제 상영편 확인을 분리했다.
